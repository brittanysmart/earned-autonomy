# Badge (Figma component set)

A small, non-interactive label used to draw attention to an item's status, category, or count. Use it for short, glanceable metadata, like a status ("Active"), a tag, or a count, placed next to or inside another element. Don't use Badge for actions. It isn't clickable or focusable; if you need something a user can interact with, use Button instead. Keep labels short (one or two words). For counts, cap at a reasonable number ("99+") rather than showing an exact large value past that point.

## Variants
- Default
- Secondary
- Outline
- Destructive
